## Featured Projects

### Agentic Observability Platform
Dockerized monitoring + automation stack using **Grafana, Prometheus, Alertmanager**, and **AI-driven agentic workflows** for real-time system & KPI observability.

**Highlights**
- **Real systems, not mock data**: OAuth2 auth, token refresh, paginated API scraping across multiple live endpoints
- **End-to-end alert pipeline**: Prometheus → Alertmanager → AI Alert Analyzer (root cause + severity + next actions)
- **AI integrated, not bolted on**: swappable analyzer backends (mock / Claude / OpenAI), token/tool-call tracking, optional MCP layer
- **Self-validating**: validates PromQL in rules & dashboards against live Prometheus
- **Tested & CI-ready**: pytest suite + linting + docker build workflow

Repo: https://github.com/Maria-cpp/Agentic-Observability-Platform
